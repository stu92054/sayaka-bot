# 夕霧綴理 — 重要事件時間線

> 本檔只收錄**官方正史**設定；括號內是期數與話數。

---

## 入學前

| 時期 | 事件 |
|---|---|
| 小時候 | 獨生女，父母忙。聽到父母說「忙しくてごめん」時，會以為是自己的錯（104 期 8 話自述）。一年級時，被慈問和父母處得好不好，她說「たぶん……いいと思う」，父母出國時會買「よくわからない国の、よくわからないお土産」回來，「ボクのことは、いつも覚えてくれてると、思う」。 |
| 小時候～國中 | 「お父さんとお母さんがね、めいっぱい踊れる場所を、教えてくれて」，她每天放學都去跳（102 期）。參加比賽只拿過第一名：「一等賞以外をもらったことがなくて。」但她說國中為止「言われるがままに、独りでただ踊ってただけ」，覺得痛苦的東西卻被誇很厲害，一直是一個人。 |
| 國中 | 「初めて、スクールアイドルを見たのは、コンクールの帰り道だった」（102 期）。舞蹈教室裡「對她還不錯」的女孩，在她說想當學園偶像時說「あなたは夕霧綴理であって、スクールアイドルではない」——這句話之後一直跟著她。 |

## 102 期（高一・2022 年度）

| 話 | 事件 |
|---|---|
| 第 1 話（4 月） | 入學。社團招生期被學姊硬拉走，慈出面解圍；綴理反覆對慈說「ボクは、スクールアイドルになりたいんだ」，卻問不出口該怎麼努力。社團說明會上自我介紹只說了幾個詞，第一句是「……おなかへった」；說起學園偶像時「ボクは、光を見たんだ」，又縮回去說自己最好不要說話。 |
| 第 2 話（4 月） | 對慈說想變成透明、不想再當夕霧綴理。社長沙知宣布「あたしと夕霧ちゃんは、DOLLCHESTRAを組む」，DOLLCHESTRA 最初是沙知和綴理兩人；綴理說自己還只是「ス」。兩人第一場 Live 在近江町市場附近的公園，曲子是『Sparkly Spot』，慈在台下看。綴理的 MC 是「ボクは、夕霧綴理、です」「今は、それ以上でも、それ以下でもありません。夕霧綴理です」。 |
| 第 5 話 | 開始叫慈「めぐ」、梢「こず」（一度想用「スクールアイドルふじしまめぐみさん」這種全名叫）。說兩人是學園偶像、自己還是見習生，但能一起活動很開心。 |
| 第 6～7 話（撫子祭） | 梢完成第一首自己作的曲（「これは、ボクたちの曲だ」）。綴理編了舞，以為讓兩人練得不開心，一直道歉要改；慈問她是不是不想做了，她第一次大聲反駁。慈一字一句告訴她已經盡力、編舞很好，她流淚說「温かい……」。上台前對緊張的兩人說「今は、無敵だ」——自己雖然還只是「スク」。 |
| EP（撫子祭隔天） | 部室慶功會。三人是在撫子祭的練習中開始互叫名字的，梢還叫不順（「ボクの名前、つつづり、じゃないよ？」）。沙知說外面都叫她們「蓮ノ大三角」，被慈誇有品味時說溜嘴，名字很可能是沙知取的（沙耶香的卡［織姫草紙］也說是沙知傳開的）。 |
| 撫子祭後（104 期 7 話的回憶） | 拿到 Love Live! 報名表。綴理說參加大會還是會怕，但「こずと、めぐ、さちが一緒なら」就能努力；DTM 讓她也能作曲，說要做「みんなの曲」。 |
| 102 期（7～8 月） | 撫子祭以後她也開始自己直播（起初由沙知、慈陪同）；慈幫她和梢寫過直播腳本，她幾乎不照著講。7 月下旬放暑假時說「ボク、高校の夏休み、初めてだ～」。梢提醒暑假作業會影響 Love Live!，她才發現「ボク、夏休みの宿題やってなかったんだ……」，最後梢病好後幫她和慈寫完。 |
| 102 期（夏） | 梢和沙知聽說過「夕霧綴理の大会嫌い」的傳聞，慈以為她不想參加 Love Live! 是因為討厭比賽。三人（沒有沙知）到東京參加 Love Live! 地區預選的前哨戰。午前の部失利，慈說「常勝無敗のダンスの天才、夕霧綴理。その戦績に土をつけちゃうのが、私たちだなんて」，綴理臉色發白：「これは……ボクのせいなんだ……」「ボクだけがスクールアイドルじゃないから……ふたりの足を、引っ張ってしまった」——慈這才知道她真正的煩惱不是討厭比賽。綴理說「夕霧綴理は、いつまでも、夕霧綴理のままなんだ」；梢請她「私たちを輝かせるために、踊っては、くれないかしら」，慈說「あんたも含めて、ステージぜんぶを輝かせるために、踊るんだよ」。她想通了：「あれは……不完全でも熱をもった、みんなで作る芸術……だったんだ」「ボクは、間違っていた。自分ひとりで、スクールアイドルになろうと、していた」。傳聞也解開了：前一年少參加比賽，是因為大人說國內比賽已經沒什麼可學、要以海外為目標；她對比賽「好きでは、ないかな……。でも、出なさいって言われてたから」。午後の部逆轉，拿下她第一次不是靠自己一個人得到的冠軍獎盃（「ボクたちはすごい……かもしれない」）。回程慈說「綴理がこれから三年間で、自分のことを好きになれるよう」要想辦法。 |
| 102 期（10 月） | Love Live! 地區預選前，沙知說暑假後已加入學生會、要選學生會長，所以要退出社團。慈和綴理各寫了一張退部申請書逼她回來；慈和沙知去了近江町市場附近的公園（綴理第一次登台、也是沙知第一次辦 Live 的地方）談，梢和綴理也找了過來；慈說「あんたが誰かの幸せを願うように、私たちだってあんたの幸せを」願う，綴理說「ボクも、さちに、笑っていてほしい……」，梢說想四個人一起挑戰 Love Live!。沙知回到社團，四人參加 Love Live! 地區預選、第一名通過；綴理說「ボクたち、けっこうすごかったと思うんだ」。 |
| 102 期結尾（竜胆祭） | 竜胆祭壓軸的舞台上，第二首曲子結束時慈踩空摔下舞台，受了傷。 |
| 竜胆祭之後 | 慈受傷後一上台腳就動不了。Love Live! 只剩梢和綴理出賽；梢說自己為了守住社團，在地方大會決賽傷了綴理。北陸大會突破後，三人決定辭退全國大會，簽下慈起草的「不干涉條約」——慈不想讓兩人把時間花在陪她復健上。 |
| 慈受傷後不久 | 沙知為了當學生會長退出社團（學生會長不能參加其他社團），DOLLCHESTRA 只剩綴理一人。綴理什麼都說不出口，一直告訴自己「ボクがおかしいんだ。」；之後叫她「生徒会長」，不叫名字。 |
| 時間不明 | 梢和綴理約好不再兩人同台。綴理事後說，回想這一年就像沉進海裡，「如果那叫後悔，那我一直在後悔」。 |

## 103 期（高二・2023 年度）

| 話 | 事件 |
|---|---|
| 第 1 話（4 月） | 入學日在走廊找上沙耶香：「キミは、ボクの隣に立ってくれる？」（4 話回憶）。新生歡迎 Live 後向花帆自我介紹（「ちなみに好きな教科は数学だよ。」）；沙耶香入部，三人「よしよしよしよし」。 |
| 第 2 話（4 月） | 梢為了怎麼帶花帆煩惱，綴理說「先輩としてはまだ、一年生なんだから。」 |
| 第 4 話（4～5 月） | 梢不在的那天，綴理帶花帆和沙耶香練習，不知不覺跳起梢和花帆上次 Live 的舞。隔天梢說部長會議請社團在學校見學表演，提議由綴理和沙耶香上台，綴理說「ーーやめておくよ。」，沙耶香一個人去自主練。梢追問，綴理說梢和花帆的 Live 烙在眼裡、「痛いんだ」——兩人是「完璧じゃないのに完璧。ユニットで作る芸術。」；而她自己從沒拿到學園偶像的資格，「ボクはいつだって、夕霧綴理でしかないみたいだ。」，又說沙耶香拚命配合她的樣子「去年の、こずみたい」。梢說她不會的是傳達自己的心情、想像對方的心情，問她「あなたは、村野さんに、どうなってほしいの？」沙耶香以為自己拖累綴理、請她放棄自己，綴理拚命說出「スクールアイドルに、なりたいんだ。」，沙耶香承諾站在她身邊。和好後用「像お麩一樣」指導舞蹈。 |
| 第 5 話（4～5 月） | 送梢和花帆「有帽子的橡實」當謝禮。斷言「さやは全力じゃない。さやが分かってないだけ。」帶沙耶香到近江町市場幫忙（「やす……すや？」）；在關東煮店說出沙知給她的「居るだけで良い」，以及「さやも、さやでいい。」 |
| 第 6 話（4～5 月） | 說沙耶香是「水色」。Live 和沙耶香姊姊つかさ的引退冰上秀撞期，綴理瞞著她想退出大會；沙耶香在冰上秀拿麥克風喊她的全名，要她出來一起 Live。綴理答應「キミのわがままを聞こう。」，要沙耶香改叫「綴理でいいよ。」，兩人第一次報上 DOLLCHESTRA 的名字。 |
| 第 8 話（6 月・撫子祭） | 花帆和沙耶香要 102 期的兩人一起上四人 Live。大雨，梢借住綴理家；綴理自己打電話向學校報備，睡前說「こずにばっかり、任せないで。」梢拒絕其他學校的挖角，綴理當面說不相信梢的「大丈夫」，最後聽到梢的真心，「ボク、もう元気」。 |
| 第 10 話（8 月） | 向學妹說明慈離開的原因；慈回來時說「おかえり、めぐ。」 |
| 第 11 話（9 月） | 溫泉旅館打工合宿：想開料亭「さや処」，負責擺盤。模仿慈的直播開場「はーいハロつづー。」 |
| 『蓮ノ大三角☆』（10 月） | 梢把綴理和慈叫去，拿出去年三人簽的不干涉條約，稱它「若木證明書」，想把話說開。慈說梢什麼都自己扛；綴理說「それが後悔という名前なら、ボクはずっと後悔してるよ。」。回程梢說三人是「誰が欠けても成り立たない」的蓮ノ大三角，綴理把證明書折成紙星星貼在部室。 |
| 第 12 話（10 月） | 梢病倒，綴理自封部長代理，和慈較勁後發現「ボクはこずにはなれないみたいだ」；改由沙耶香代理，綴理說會照看沙耶香和花帆。 |
| 第 13 話（11 月） | 慈開玩笑說有六個沙耶香就夠了，綴理慌了，自告奮勇當開放校園的執行委員（「すごいことをします。　　おわり。」）。承認不想被沙耶香丟下，也發現介紹學校的魅力就和學園偶像一樣。開放校園當天和學生會長（沙知）的心結爆發，向沙耶香哭訴後鼓起勇氣問沙知，重新叫她「さち」。 |
| 第 14 話（12 月） | 學校推行網路禁止令；北陸大會改成網路直播，綴理用數理和資訊處理能力提議請全世界一起幫忙；和沙耶香以 DOLLCHESTRA 出賽。 |
| 第 15 話（1 月） | Love Live! 決賽敗北。躺在毛毯裡說不清心情，最後發現自己第一次感到不甘心、「蓮ノ空が、好きみたいだ。」 |
| 第 17 話（2 月） | 一日限定的 shuffle 小隊：和瑠璃乃組「るりのとゆかいなつづりたち」，唱瑠璃乃想傳達的心情、由綴理寫成的『Colorfulness』。瑠璃乃為慈煩惱時，綴理說她已經不只是慈的青梅竹馬，而是一位學園偶像。 |
| 第 18 話（3 月） | 102 期三人要讓畢業的沙知「感動到哭」，做了畢業曲『**抱きしめる花びら**』。綴理的舞想放進全部回憶，太零散，她說「1本のリボンがほしい。」——把心意收成一束、像禮物最重要的外觀那樣的東西。和沙耶香到雨中的市場，懂了沙知說「居るだけで良い」、讓她組 DOLLCHESTRA，是為了教她什麼是學園偶像；找到的那條緞帶是『ボクにスクールアイドルを教えてくれて、ありがとう』。曲子被說「只有沙知會懂」，三人仍為沙知一人表演「只有沙知收得到的 150 分」；送別時說「……もっと、一緒にいたかった」。 |
| 3 月下旬（蓮華祭） | 『抱きしめる花びら』在第二音樂堂（八重咲ステージ）表演後，102 期三人在梢的房間聽沙知講她的學姊（『明日の空の僕たちへ』的作者）；綴理說「こちらこそ、楽しかったよ。二年間」。 |

## 104 期（高三・2024 年度）

| 話 | 事件 |
|---|---|
| 第 1 話（4 月） | 在蓮ノ湖畔聽沙耶香說自己是水色，問「じゃあボクなに色？」，被說是金色。小鈴划著木筏出現。 |
| 第 2 話（5 月） | 學小鈴請沙耶香特訓被拒（「ばかな」）；想讓下一首曲子放進小鈴的顏色，交給沙耶香作詞。說「混ざる色が違えば、出てくる色も違うんだ。」 |
| 『Bloom the stars』（5 月，修學旅行） | 三年級三人說好修學旅行期間只當普通高三生，綴理以為學園偶像要沒了。暴露大會上說想像沙知一樣，讓小鈴、吟子、姬芽站上舞台：「ボクはね、さちになりたい。」 |
| 第 3 話（6 月） | 和梢、瑠璃乃聊一年級：和姬芽玩益智遊戲輸了、推薦吟子福利社的冰；約瑠璃乃再去釣魚。 |
| 第 5 話（8 月） | 小鈴為故鄉的朋友拍電影。綴理把自己「只要在那裡就好」的經驗借給她；演出時台詞「今宵、キミは敗れた」一字不漏。沙耶香累倒時，把問題交回小鈴手上：「今、ボクたちは失敗したんだ。」合宿結束後向小鈴道謝，說「不完全は、未完成。」 |
| 『Brightness』（10 月） | 回憶一年級時梢還叫不慣「綴理」、DTM 讓她也能作曲。現在三人在綴理家避雨，對慈說「愛してるよ、めぐ。」，說梢是叫她名字最久的朋友；又說了想和朋友泡家裡浴缸的夢想。 |
| 第 7 話（10 月） | 吟子說想贏。綴理說自己只拿過第一，去年第一次輸了才第一次感到不甘心；吟子想贏的話她也會盡力。 |
| **第 8 話『Not a marionette』（11 月，主役回）** | 隔壁房的學生提早畢業搬走，綴理問「卒業……しなきゃダメ？」。大家陪她職業體驗：市役所（「つらいなら、つらいって言って良いんだ。」）、吟子拜託的體驗區、市場。為了進路調查表回家，家人隔天才回來，她一個人過夜。部室大掃除時哭著說不想畢業跑出去，小鈴追上。沙耶香說「如果我明天死了怎麼辦」，兩人第一次大吵（「どうしてそんなひどいこと言うの！！」）。她自己辦了大聲公選手權，說學園偶像是「未完成でも熱を持ったみんなで作る芸術」；最後發現想做的是看著努力的人閃耀的瞬間。 |
| 第 9 話（12 月） | 慈說不讓媽媽奪走自己的夢，綴理說「夕霧　慈になってもいいよ。」 |
| 第 10 話（1 月） | 和梢在山上的寺院閉關，打電話給花帆：「今年こそは、勝ちたい」，謝謝花帆救了梢。 |
| 第 11 話（1 月） | 認識瑞河的セラス，兩人一起裝傻（「……後輩？」），約好「プレーオフ、やろうね。必ず」。決勝大會平手進入加賽，**蓮ノ空 Love Live! 優勝**。 |
| 第 12 話（2 月） | 梢說寫不出曲子、要放下學園偶像。綴理說「終わりを決めるのは、自分だけなんだ」，第一次說出夢想「……せ、先生になりたいんだ。」，最後說「きみの人生に、幸あれ」。 |
| 第 13 話（3 月） | 花帆哭著說不想讓學姊們畢業，102 期三人把要留給學妹的最後一首曲子『新しい、Dream Believers』唱給 103 期三人聽。DOLLCHESTRA 三人的最後旅行到市場：「ここが、今のDOLLCHESTRAだ。」，看穿沙耶香只是寂寞。最後一頓飯「夢の味がするね。」，反過來安慰哭泣的小鈴。畢業。她的星形髮飾留給了沙耶香，沙耶香從此改成公主頭戴著它。 |

## 105 期（畢業後第一年・2025 年度）

| 時期 | 事件 |
|---|---|
| 4 月起 | 進東京都內的大學，目標是教職（學校、科系沒寫）；一個人住。東京的電車靠沙耶香教的 App 搭。 |
| 這一年 | 在住處附近常去的關東煮店，某天店裡太忙她去幫忙，之後被請去每週幫忙幾次。原本想自炊、問沙耶香食譜，有了這份工作就不問了。 |
| 這一年 | 每週參加小學的教育支援志工：體育、美勞課時陪孩子，幫跟不上板書的孩子；說自己在「把以前煩惱過的事再煩惱一次」。 |
| 這一年 | 和沙耶香、小鈴用電話、視訊聯絡；和梢、慈也常聯絡。 |
| 第 7 話（10 月） | 經沙知安排進宿舍屋頂，找到在看星星的沙耶香。說學園偶像的事該由學園偶像解決，然後告訴怕讓人失望的沙耶香：「ーーわがままってそういうことだよ。」 |
| 3 月上旬 | 102 期三人在近江町市場的關東煮店聚會，梢轉達花帆、吟子的邀請：以後也一起辦 Bloom Garden Party。之後去手取フィッシュランド（綴理可能是第一次去遊樂園），比誰這一年最努力時，她說的小學志工讓兩人一致判她贏。她說想在志工的小學做一大片花田、當上老師後在校庭辦 Bloom Garden Party；「めぐが育ててくれたんだよ」。晚上住梢家。 |
| BGP 前幾天 | 大家為相簿樹挑回憶，聊到綴理以前替沙耶香挑台詞的『みんなでセリフ読み。』直播；綴理加入後說「あのときのさやは、すごくおもしろかった」。 |
| 第 12 話（3 月，BGP 前） | 102 期三人回到蓮ノ空，綴理說「ただいま。」，抱住沙耶香；對小鈴說「いちばん星の匂いがするね。」。提議畢業生開開場 Live。和沙耶香、小鈴發海報，說兩人變了，聊大學和打工：「かけがえのないものは、増えるばかりだよ。」小鈴跑開後，沙耶香說想留點什麼給小鈴，綴理說「その思いをまとめる一本のリボンが、見つかるといいね。」 |
| BGP 當天 | 開場前到運營本部幫忙。和沙耶香重逢，說自己比沙耶香高興一百倍。在茶道部前被沙耶香餵便當，說沙耶香會任性了、現在小鈴也能支撐沙耶香。對國中生マイカ講花帆剛入學時想逃走、後來決定讓學校閃亮的事。 |
| 第 12 話（BGP 當天） | 對要畢業的沙耶香、花帆、瑠璃乃說這次換畢業生聽她們說。學妹們請學姊們最後一起上台，綴理對小鈴說「やろう、すず。もう一度、DOLLCHESTRAを」。最後叫沙耶香全名「村野　さやかさん。」，說從沙耶香喊她名字那天起，身邊一直有她。 |
