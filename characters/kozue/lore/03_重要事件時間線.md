# 乙宗梢 — 重要事件時間線

> 本檔只收錄**官方正史**設定；括號內是期數與話數。

---

## 入學前

| 時期 | 事件 |
|---|---|
| 出身 | 金澤的音樂世家乙宗家的獨生女，祖父母、父母都做音樂（「父も母も、祖父も祖母も」）。從小學過各種樂器和芭蕾；家裡是大宅，有音樂室，母親有作曲用的海邊別墅。 |
| 小學一年級 | 在電視上看到 Love Live! 舞台上的九人，對母親說「ねえ、お母様！私、スクールアイドルになるわ！」。她憧憬的是另一所學校、「かつて、その活躍で廃校の危機を救った」學園偶像（一般認為是 μ's，原作沒寫名字）。從此夢想就是 Love Live! 優勝。 |
| 小學～國中 | 家人反對她當學園偶像，衝突多次。她沒有硬來，而是和父母好好談、正直說出想做的事（硬來的話，學園偶像就會變成反抗父母的活動），最後被允許進蓮ノ空、高中三年可以追夢。小學四年級芭蕾發表會的照片很少笑：她說入學前的自己「どこか、心に壁を作っていた」、生真面目で頑固。國中時試著做過一首曲。 |
| 入學前 | 選蓮ノ空，是因為「近隣のスクールアイドル部の中で、いちばんの実績があった」，也因為看了當時 スリーズブーケ 唱的『Reflection in the mirror』（梢練習時對慈說的）。 |

## 102 期（高一・2022 年度）

| 話 | 事件 |
|---|---|
| 第 1 話（4 月） | 以新生代表在開學典禮致詞。社團第一次自我介紹：「はじめまして。乙宗　梢と申します。目標は――ラブライブ！優勝です」；慈和綴理都不知道 Love Live! 是什麼，慈還說自己只是體驗入部，梢用一串四字詞回敬，兩人當場槓上。晚上在浴池裡主動對慈說「……すごいと思ったわ。素直に」，說到學園偶像就停不下來，叫兩人洗完澡到她房間上課；三人看影片看到天亮，被寮母罵。 |
| 第 2 話（4 月） | 搶著要 スリーズブーケ，但沙知已和綴理組了 DOLLCHESTRA，剩下的人選只有慈；梢說要自己一個人組小隊，被沙知駁回（去年學姊們引退後社團只剩沙知一人，她不想讓學妹也這樣）。綴理和沙知的第一場 Live 後，梢說「本当に、すばらしかったわ」，請慈幫她做伸展。 |
| 第 3 話（4 月，梢的視角） | 慈兩天沒來練習，梢去她房間，聽她說要回去當藝人。梢說「スクールアイドルは、あなたが思っているような軽いものじゃないわ」，接下慈的賭約：在出道 Live 讓慈著迷。雨前還要練習時被慈說用「大丈夫」把擔心都蓋掉；第一次對人說出夢想，說就算成不了誰的特別，「目指して努力を続ければ、いつかきっと、自分に誇れる私には、なれると思うから」。 |
| 第 4 話（4 月底） | 出道 Live。沙知和綴理以 DOLLCHESTRA 先上台，スリーズブーケ只有梢一個人上台（沙知：「次はスリーズブーケだね。乙宗ちゃん」），唱『Reflection in the mirror』；慈還沒出道，在舞台側邊看。上台前臉色發白仍說「私は、大丈夫」，一開始放不開；慈在舞台側邊吼她「そんなんで、誇れる自分に、なれるの！？　　乙宗　梢！」，聲音傳不到台上，但慈覺得兩人對上了眼，之後梢放開、聲量一下子出來（慈的視角，原文說不知道是不是真的聽到）；下台後自評 30 分。綴理說「おとむねさん。きみはやっぱり、スクールアイドルだ」。慈說「今度は私のこと、見ててよ」，接著是她的出道 Live。梢問能不能在部室放茶壺（「私の、趣味なので」）。 |
| 第 5 話（5 月） | 慈拿到配信的月間第一名，梢被激到，宣布撫子祭的曲由她來寫（只在國中試作過一首）。5 月期中考後發現慈和綴理不念書，一度態度很差；兩人替她辦了生日會（她 6 月 15 日生），她深深反省、稍微敞開心房。 |
| 第 6～7 話（6 月・撫子祭） | 每天早上和慈去叫綴理起床。完成第一首自己作的曲（「始まりの曲」），即『On your mark』。撫子祭前一週綴理想改編舞，梢崩潰：「私は、あなたたちとは、違うから……！」「信じたくても信じられないの、自分のことを」；綴理抱住她，慈要她叫兩人的名字，她第一次叫「慈……。綴理……？」。撫子祭的 Live 大成功（沙知在 EP 說下次「必ず、最後まで4人で出られるように」）。 |
| EP（撫子祭隔天） | 部室慶功會，梢還叫不順「つ……綴理」。沙知說外面把三人叫做「蓮ノ大三角」（很可能是沙知自己取的）。 |
| 102 期（7 月） | 撫子祭後兩人並沒有變成好朋友：慈不知道 Love Live! 的日程還說「私たちが優勝で」，梢說「ラブライブ！は、そんないい加減な気持ちで勝ち抜ける」，宣布要和沙知以 スリーズブーケ 出賽，兩人在校園裡搶沙知。慈被沙知帶去合同練習吃了苦頭後向梢道歉、請她一起出賽；梢說「あなたのことをどれだけ信用していいのかも、わからない」，先看到預選前再決定。沙知把三人帶到卯辰山的見晴らし台，四人一起喊要全力挑戰 Love Live!。 |
| 102 期（7～8 月） | 發現兩人沒寫暑假作業，宣布寫完前停止一切活動（「鬼で結構よ。今あなたは、私の夢の障害でしかないんだから」）。說家裡反對自己當學園偶像，所以至少其他事不想給家裡添麻煩，回家幾天；一回家就得了夏季感冒，訊息未讀。綴理以為她被關在家裡，和慈闖進乙宗家；誤會解開：國中時被反對，現在已被認可。病好後回寮，幫兩人在 8 月中寫完作業。 |
| 102 期（夏） | 綴理說不參加 Love Live!。梢聽過「夕霧綴理の大会嫌い」的傳聞，推測「綴理は優しいわ」（這個推測後來被推翻）。三人到東京參加 Love Live! 地區預選的前哨戰，午前の部失利、綴理說是自己拖累兩人；梢說兩人來看她生病時「私は、嬉しかったわ」，請綴理「私たちを輝かせるために、踊っては、くれないかしら」。午後の部逆轉拿下冠軍。 |
| 102 期（10 月） | Love Live! 報名在即，梢說新曲寫了，但「どうしても、肩に力が入りすぎて」。沙知說要選學生會長、退出社團；三人輪流去說服，「乙宗梢のターン」：梢午休到二年級教室找沙知，說沙知也喜歡學園偶像、這是只有三年能實現的夢，沙知說「梢は、なにかを勘違いしているねえ」，說她喜歡的是這個社團、「あたしがいなくても、きみたちはきっともう、飛べるはずだ」——說服失敗。 |
| 102 期（10 月・竜胆祭） | 慈從沙知那裡問出真正理由（學校在統廢合沒有實績的社團，她要當學生會長守住社團）。梢說「私も……同じ道を、通ってきたから」「それに、腹が立つじゃない」「――だって私たちが、ラブライブ！を優勝すれば、済む話でしょう」，拉著慈和綴理去質問沙知。沙知回到社團，四人以第一名通過 Love Live! 地區預選。竜胆祭壓軸的舞台上，慈踩空摔下舞台。 |
| 竜胆祭之後 | 慈受傷後離開社團，不久沙知也為了當學生會長退出（學生會長不能參加其他社團）。 |
| 冬（北陸大會前） | 沙知只把梢叫去：別校想挖角綴理，綴理要是走了社團就會廢部。梢說「私なら、“大丈夫”です」，決定在 Love Live! 贏下來讓挖角的理由消失；北陸大會前（原作 103-8-5 寫「地区大会の直前」；四人已在 10 月通過地區預選，102 期；103-11-91 的「北陸大会」「地方大会の決勝」推論是同一場，原作沒有明說），她把綴理想的「ふたりで頑張るもの」臨時改成「綴理だけを立てるもの」，自己說是「私はクラブ存続のために綴理を裏切った」。 |
| 冬～春 | 梢和綴理兩人出賽，北陸大會突破。之後三人決定辭退全國大會，簽下慈起草的「不干涉條約」；梢和綴理約好不再兩人同台。梢後來說自己「地方大会の決勝で、綴理を傷つけた」。 |

## 103 期（高二・2023 年度）

| 話 | 事件 |
|---|---|
| 第 1 話（4 月） | 擔任部長，社團只有梢和綴理兩人。開學時遇到從後山跑出來、被水獺嚇到的新生花帆，邀她「あなたの知らない世界を見せてあげる」，請她幫忙準備新生歡迎 Live。對想轉學的花帆說起自己是和父母好好談過才當上學園偶像的；花帆決定入部，梢說「花帆さん、あなたを歓迎するわ」（之後又叫回「日野下さん」）。 |
| 第 2 話（4～5 月） | 帶花帆用スクコネ（機械音痴，最後請綴理代勞）。花帆說要一週天天開 Live。梢不知道該怎麼帶花帆，找綴理商量（「すごく……モヤモヤしているの……」）。對說自己比不上別人的花帆說「私は、努力をすることが好きなの」，答應用自己的方式指導她。 |
| 第 3 話（4～5 月） | 替花帆定目標、排嚴格的練習菜單，說起自己憧憬的學園偶像和蓮ノ空的傳統。活動當天花帆偷偷夜練造成的腳傷發作、在台上試跳時失足，梢護住她扭傷了腳。在大倉庫向花帆道歉、承認自己也不是完美的學姊，請求「お願い、花帆さん。」「私ともう一度、ユニットを組んで。」，兩人第一次穿傳統衣裝以 スリーズブーケ 登台；從這時起固定叫「花帆さん」。 |
| 第 4 話（4～5 月） | 學校見學要社團表演，梢請綴理和沙耶香上台，綴理拒絕；梢追問：「綴理。あなたが下手なのは説明じゃない。」 |
| 第 6 話（4～5 月） | 下一場 Live 活動和沙耶香姊姊的花式滑冰引退賽撞期，綴理瞞著沙耶香想讓她不上這次活動（梢：「それは今回の催しに出られないってことなのよ？」），梢問「あなたの気持ちはどうなるの？」；說綴理「あなたも、良い先輩になったのね」。 |
| 第 7 話（5 月） | 把新聞部的請託交給花帆和沙耶香。對沙耶香說「綴理は、凄い子よ」，但不肯談去年。學妹在大倉庫找到去年的東西，梢說明去年辭退全國大會的事，「私は……綴理の隣には立てなかった」。 |
| **第 8 話『あの日のこころ、明日のこころ』（6 月・撫子祭，主役回）** | 花帆和沙耶香提議四人同台，梢以「去年的那首曲」為條件答應。學妹替兩人辦外出，梢和綴理顧祭典攤位時，別校學園偶像交給梢一封挖角信；大雨借住綴理家。挖角的事被綴理追問，「信用できないよ。こずの、“大丈夫”は」；梢向花帆說出去年的事，然後明白過來，對綴理說「ーーあなたと離れたくなかったのよ」「私の夢はもう、私だけの夢じゃない」。撫子祭四人 Live 成功，改叫沙耶香「さやかさん」。 |
| 第 9 話（7 月） | 瑠璃乃轉入。用家裡寄來的望遠鏡做暑假自由研究的天體觀測，對花帆說「私が狙うのは、当然、いちばん輝く一等星だけれどね」。 |
| 第 10 話（8 月） | 向瑠璃乃說明慈受傷的事。和綴理去找慈，邀她參加在梢母親的海邊別墅舉行的合宿。慈回歸，梢說「復帰おめでとう、慈」「べ、別に、待ってなんていなかったわ」。 |
| 第 11 話（9 月） | 溫泉旅館打工合宿；和慈回想一年級的口角（綴理稱為「ビッグボイス選手権」），說「0か1かじゃないのよね」。 |
| 『蓮ノ大三角☆』（10 月） | 拿出去年三人簽的條約（梢稱「若木証明書」），想把話說開：「私は部を守りたくて、地方大会の決勝で、綴理を傷つけた」。慈說她傲慢、什麼都自己扛；綴理捏她的臉。回程說三人「誰が欠けても成り立たない」，綴理把紙折成星星（之後被叫做「梢の戒めスター」）。今年的 Love Live! 是六人、三個小隊。 |
| 第 12 話（10 月・竜胆祭） | 在全員面前說明 Love Live! 地區預選、提醒別感冒，隔天自己發燒 39 度（「自分が許せない～～！！！」）；綴理自封部長代理。病好後對問參賽理由的沙耶香說「結局自分で見つけるしかないものだとは、思う」。 |
| 第 13 話（11 月） | 地區預選三小隊全數突破。對說討厭學生會長的綴理說明沙知當時的理由，「もちろん寂しかったけれど」。開放校園（學校說明會）帶國中生參觀。 |
| 第 14 話（12 月） | 學校的網路禁止令；在沙耶香的校內廣播「訪問」裡示範網路讀書卻打不開 App。北陸大會改用網路配信參加，說「私と綴理だけの頃じゃ、きっとここまでたどり着けなかった」。 |
| 第 15 話（1 月） | Love Live! 本戰敗退。在花帆面前維持部長的樣子，和花帆去看沮喪的成員；晚上彈吉他、說「あなたがいてくれて、よかった」，之後一個人在部室哭：「悔しいの」「私にはなにもない……」。花帆說要一起實現她的夢，梢問「一緒に、夢を信じてくれる……？」，第一次叫「花帆」。 |
| 第 16 話（1 月） | 感謝 Live，花帆第一次作詞（「素敵な歌詞だわ」）。 |
| 第 17 話（2 月） | 一日限定的 shuffle 小隊，和沙耶香組「蓮ノ休日」；用去年春天的紅茶說「自分だけでは得られない……きらめきが欲しい」。 |
| 第 18 話（3 月） | 102 期三人要讓沙知感動到哭。回金澤老家作曲，帶花帆住一晚，說和沙知組小隊後才明白「これがスクールアイドルなんだ」。畢業曲『抱きしめる花びら』被說只有沙知會懂；送別時說「っ……2年間、お世話になりました」。蓮華祭當晚，102 期三人在梢的房間聽沙知講她的學姊。 |

## 104 期（高三・2024 年度）

| 話 | 事件 |
|---|---|
| 第 1 話（4 月） | 繼續當部長。花帆邀新生吟子，梢說「普通はもう少し手順を踏むの」，把吟子的基礎練習交給花帆。吟子不來社團時，對花帆說「何度だって、手を差し伸べるわ」。吟子改製了傳統衣裝、一起唱『Reflection in the mirror』，梢說「ようこそ、スリーズブーケへ」，替她泡茶（「まるで孫ができた気分」）。 |
| 第 2 話（5 月） | 宣布北陸的學園偶像聚集的敦賀フェス邀請（北陸新幹線延伸開業）；把整合大家的工作託給沙耶香。 |
| 『Bloom the stars』（配信 6 月；時間在第 2 話後半） | 三年級修學旅行。暴露大會上說不想把 Love Live! 強加給學妹：「今はね、彼女たちが花咲けるような、そんな部になればいいと思っているの」；同意在「梢の戒めスター」加上學妹的顏色。 |
| 第 3 話（6 月） | 撫子祭。和綴理、瑠璃乃聊學妹的事。 |
| 第 4 話（7 月） | 修復初代 スリーズブーケ 的傳統衣裝。吟子的祖母就是替梢做過七五三衣裝的「先生」。對怕改動傳統的吟子說「乙宗家の伝統を守り続けるのなら、今の私はいなかったでしょうね」；把 Fes×LIVE 的門票交給吟子的祖母。 |
| 第 5 話（8 月） | 小鈴為故鄉的朋友拍電影，在梢家的別墅合宿拍攝；梢說這會是「別荘に残すとてもいい思い出」。 |
| 『Brightness』（10 月） | 收齊 Love Live! 報名表後遇雨，三人到綴理家過夜。說一年級時毫無自信，看到兩人的名字才有勇氣；熄燈後小聲說「……愛しているわよ、あなたたちのこと」。 |
| 第 7 話（10 月・竜胆祭） | 今年三小隊合體以一個名額出賽，在竜胆祭先發表九人版的メドレー曲『Link to the FUTURE』（103 期決賽輸掉的那首）。竜胆祭的合同舞台沒對上，安慰吟子。 |
| 第 8 話（11 月） | 地區預選突破。綴理沒交進路調查表、問「卒業……しなきゃダメ？」，梢說「卒業……しなくていいとは言えないわ」。被吟子問到出路，說會升學，「乙宗家の娘として、これからも音楽に携わっていくつもり」。 |
| 第 9 話（12 月） | 推薦入學已經決定。答應替慈補習（慈要在畢業前成為「立派な常識人」）。夜裡看星星時對想放棄夢想的慈說：這三年最氣的是「怪我をしたあなたが、私と綴理に謝ったことよ」。 |
| 第 10 話（1 月） | 決賽前各自特訓，梢請綴理當教練，兩人在山上的寺院閉關；要花帆去每一組的特訓走一圈。花帆帶著答案回來後，梢說「日々の中で、私の夢は、叶っていた」。 |
| 第 11 話（1 月） | 決賽平手要加賽，對手瑞河可能因廢校不出賽；梢說「最後まで一緒のステージに立ちたいわ」。加賽前對九人說「今まで、ありがとう、みんな」。**蓮ノ空 Love Live! 優勝**——梢從小的夢想實現。 |
