# 日野下花帆 — 重要事件時間線

> 本檔只收錄**官方正史**設定；括號內是期數與話數。

---

## 入學前

| 時期 | 事件 |
|---|---|
| 幼年 | 長野縣出身，家裡是種ラナンキュラス的花卉農家；名字「花帆」也從這種花來。上面沒有兄姊，下有兩個妹妹ふたば、みのり（雙胞胎，直播「入学1年記念雑談！」花帆說「双子の妹がいるんだけどね」）。 |
| 幼年 | 體弱、常發燒，住過好幾次院；在病房裡讀書。住院時和隔壁的セラス成了「院友」，比セラス先出院。 |
| 小學 | 生病常被排除在遊戲外，覺得自己「沒辦法像溫室裡的花那樣整齊地開」，連名字都像被期待「正確長大」而不太喜歡。兩個妹妹帶她到山裡，看到一株自己長出來的ラナンキュラス——「大事なのは、ちゃんと『花咲くこと』なんだ」。 |
| 中學 | 上中學後身體好轉，但父母仍過度保護：接送上學、門禁嚴，放學就回家，沒有特別要好的朋友。住院變少後功課和運動都落後，焦慮、對母親和妹妹發脾氣。 |
| 國三 | 和父母「粘り強～く交渉」拿到報考蓮ノ空的許可（母親是蓮ノ空校友），說好不合格就放棄。她以為蓮ノ空是「駅前にあって、ピッカピカの校舎」——其實只是自己擅自想像（母親只講過自己當年的回憶）。考上。 |

## 103 期（高一・2023 年度）

| 話 | 事件 |
|---|---|
| 第 1 話『花咲きたい！』（4 月） | 入學日在公車上和村野沙耶香坐隔壁，一路說個不停。隔天發現學校在山裡、規則一大堆，萎靡到向沙耶香道歉；說出「あたしね、ずっと花咲きたかった。」（103 期 1 話）。決定「脫走」，在後山被學校養的水獺嚇哭，遇到乙宗梢；梢看穿她在脫走卻說不告密，請她喝茶、帶她看スクールアイドルクラブ的 Live。花帆在台上看到「きらきらに、花咲いている」的梢；同場沙耶香決定拜夕霧綴理為師入部。花帆以「經理」名義幫梢準備新生歡迎 Live（搬資材、試跳），一面又想轉學——轉學手續的截止日剛好是新生歡迎會當天；打電話向母親抱怨學校和想像的完全不同。最後在同班的えな、びわこ、しいな面前宣布「学校やめるの、やめることにする」，要讓這所學校「みんなの笑顔で満開に」，對梢說要當「みんなを花咲かせるスクールアイドル」，和梢一起上台。同學們成了她的第一批粉絲。 |
| 第 2 話『ダメダメ⇒世界一！？』（4 月） | 正式入部（綴理爆料梢每天都說「花帆要是能入部就好了」）。對沙耶香說「死ぬまで一生、スクールアイドルだよ！」（103 期 2 話）。看了沙耶香的スクールアイドルコネクト練習直播、再看自己的影片，大叫「ダメダメだぁ」。梢說自己沒有花帆的「愛嬌」，能給人看的只有努力的軌跡；花帆請梢教她梢的方式。一週每天的 Live 最後一天，在台上宣言要成為「世界でいちばんのスクールアイドル」。 |
| 第 3 話『雨と、風と、太陽と』（4～5 月） | 為了第一次參加大型活動接受梢的特訓（晨跑從 500 公尺就喊不行開始）；向梢說起家裡的ラナンキュラス和小時候的事。想穿上スリーズブーケ的傳統衣裝，瞞著梢半夜加練；腳踝不適卻謊稱「撞到衣櫃小指」，上台前失足，梢為護她扭傷（「ひねっただけ」），兩人的舞台泡湯。花帆讀了スクールアイドルノート，請梢「好好罵我」；梢也請花帆罵她、請她再組一次小隊——花帆反過來說「あたしと一緒に、スクールアイドルしてください！」。從這時起梢固定叫她「花帆さん」。 |
| 第 3 話 『ハロめぐチャンネル！』 | 慈的個人直播；花帆沒有台詞，只被提到 7 次。 |
| 第 4 話『わたしのスクールアイドル』（4～5 月） | 梢不在的那天請綴理指導自己（綴理用「えだまめ」「そらまめ」當口令）。支持沙耶香與綴理的 DOLLCHESTRA：「あたし、さやかちゃんの歌もダンスも、すっごく好きだから！！」（103 期 4 話）。 |
| 第 5 話『顔を上げて』（4～5 月） | 跑到近江町市場看在れいかさん那裡幫忙的沙耶香，說「さやかちゃんの周り、すっごく綺麗に花咲いてるみたいだね！」（103 期 5 話）。 |
| 第 6 話『わがまま on the ICE!!』（4～5 月） | 沙耶香帶她去滑冰場；看到沙耶香在花式滑冰大賽優勝的報導。沙耶香為冰上秀與 Live 撞期、被綴理說「學園偶像不是被逼著做的」而動搖時，花帆說自己一直怕沙耶香退社，「あたしは、フィギュアが凄くなってもスクールアイドル辞めずに」「頑張ってくれてるさやかちゃんが好きだから。」（103 期 6 話）。在冰上秀看到沙耶香和綴理以 DOLLCHESTRA 上台。 |
| 第 7 話『センパイとコウハイ』（5 月） | 宣布目標「100 萬人一起 Live」（沙耶香：巨蛋也裝不下；花帆：「ぎゅぎゅっと」）。和沙耶香接下新聞部的社團介紹報導，去大倉庫調查梢和綴理的過去，在兩人面前觸到痛處；哭過之後穿著睡衣去找梢，提議撫子祭由四人一起 Live。 |
| 第 8 話『あの日のこころ、明日のこころ』（6 月・撫子祭） | 用「黏在一起直到步調一致」的作戰撮合梢和綴理（失敗）。梢收到挖角卻要拒絕、被綴理說不信任她的「大丈夫」；花帆坐到梢身邊聽她說，最後送她去找綴理：「……がんばれ、梢センパイ」。撫子祭四人 Live 之後，梢請沙耶香直接叫名字；花帆宣布「100万人ライブへの、第一歩！！」。 |
| 第 9 話『ルリ・エスケープ』（7 月） | 從加州轉來的大沢瑠璃乃入部。花帆對梢說溜嘴：「センパイが鬼になったのは、あたしに朝練させようとしてから」（103 期 9 話）。瑠璃乃要退出，花帆搭公車追出去求她再給一次機會；梢讓她看望遠鏡，她反省自己只想要「新部員」，「どこにも『新入部員』なんて名前の子は、いないんですよね！」。最後迎回瑠璃乃。 |
| 第 10 話『ルリめぐ・ファンファーレ』（8 月） | 夏季合宿住在梢家的別墅。勸瑠璃乃別隨便請梢特訓（「ミイラにされちゃうよ」），梢回「花帆さんのドライフラワーは、さぞかし綺麗でしょうね。」（103 期 10 話）。直接問藤島慈還能不能跳舞（「慈センパイって、もう、ダンスできないんですか！？」，103-10-4），被沙耶香制止。在舞台側為瑠璃乃和慈的みらくらぱーく！加油。 |
| 第 11 話『スクールアイドルクラブのために！（？）』（9 月） | 溫泉旅館打工合宿：提議在每個房間擺主題花（梢決定主色和配色），「あたしも、好きなことがこんな形で活きるなんて、びっくりです！」（103 期 11 話）。 |
| 第 12 話『期待はおもい！』（10 月・竜胆祭） | 梢感冒，一年級三人去學生會申請舞台，學生會長沙知出了三個試煉。花帆借來之前和梢幫忙過的咖啡店制服在街上發傳單，發現自己當學園偶像是因為「あたし自身が花咲きたかったから」。 |
| 第 13 話『追いついたよ』（11 月） | オープンキャンパス當 1 號接駁車的導覽，對來參觀的人保證最後的野外 Live 會讓大家心裡開出大花。下雨時想到把大量的傘連起來當屋頂、讓傘也變成大花。 |
| 第 14 話『Link！Like！』（12 月） | 學校推行網路禁令、又加上外出禁令。花帆怕被粉絲遺忘、想爬過校門卻爬不過，想起小時候只能從窗戶看外面；沙耶香用テザリング把她的手機接上網路。花帆從這裡想到點子，社團以網路直播打 Love Live! 北陸大會（103-16-1 花帆稱為「テザLink！ライブ」）。三小隊合作的『Link to the FUTURE』也是花帆提議的。 |
| 第 15 話『夢を信じる物語』（1 月） | Love Live! 決賽輸了。梢泡楓糖紅茶、彈吉他，花帆問「どうしてあたしだったんですか？」、哭著說自己拖累了梢。之後對消沉的梢立誓「今度こそ、あたしたちでセンパイの夢を叶えましょう！」「梢センパイには、日野下　花帆がいるんだって」。全員在夕陽下許來年的願，花帆列了一大串（花咲、讓大家笑、100 萬人 Live、基礎練習、少吃零食、Love Live! 優勝）。梢從這時起叫她「花帆」。她從此不再翹晨練。 |
| 第 16 話『Special Thanks』（1 月） | 提議辦答謝 Live（「みんなにお礼のライブしたい」，103-16-1）。第一次負責作詞，被沙知拉去散步、一起送邀請函。 |
| 第 17 話『ルリ思う。』（2 月） | 洗牌小隊：和慈組「かほめぐ♡じぇらーと」（103 期 17 話），一起直播 8 小時、玩「花帆先生」審問遊戲，慈叫她「花帆後輩」。 |
| 第 18 話『いずれ会う四度目の桜』（3 月） | 在梢的老家住一晚，一起作給沙知的謝禮曲；梢的母親親自下廚，花帆想一起睡、梢答應。開始叫沙知「沙知センパイ」。沙知畢業前，花帆說沒有梢就待不下這所學校，代表大家謝謝沙知留下了スクールアイドルクラブ。 |
| 103 期 4 月 | 第一次 Fes×LIVE 前後，和沙耶香去金澤フォーラス、拍貼紙照；覺得只讓沙耶香陪自己玩、自己卻跟不上她的練習而煩惱，接到母親電話後去找沙耶香，兩人成了「親友」。細節寫進 lore 前要再讀原文。 |

Believe your live.』（1 月） | Love Live! 決賽前，和吟子去瑞河女子「偵察」，發現對手陣營裡有院友セラス；聽她說住院時被瑞河的學園偶像救了。看了桂城泉的實力，花帆認為「自己以前不夠認真」，梢給她「找出不足之處」的課題。夜裡接到和梢在山上寺院閉關的綴理的電話（「こずを助けてくれて、ありがとう」）。和吟子大吵（吟子：「花帆先輩の、だら！」），哭著說只是不想再看梢哭。瑠璃乃帶兩人去找寮母，得到優勝當年的『Dream Believers』和部長留下的スカーフ。花帆的答案：她忘了「楽しい」。梢說自己的夢在日常裡已經實現。 |

## 105 期（高三・2025 年度）

> 105 期蓮ノ空**不參加 Love Live!**，全員投入花帆提出、在 105 期第 3 話命名的「**Bloom Garden Party**」（ブルパ，讓所有人都能花咲的舞台，3 月舉辦）。

| 話 | 事件 |

## 103 → 105 的成長軸（一句話版）

1. **103 期**：「這裡是沒有陽光的日陰」→「靠自己的力量花咲」，再到「和梢一起花咲」、立誓實現梢的夢。
2. **104 期**：當了學姊、學會自己開口；為了讓梢優勝差點忘了「楽しい」，被吟子罵醒；優勝後想讓「更多的人花咲」。
3. **105 期**：當部長、放下 Love Live!，做「誰都能花咲的地方」；學會被扶持（「那個『大家』裡也可以有我」），最後的答案是「夢中になること」加上「踏出第一步的勇氣」。
