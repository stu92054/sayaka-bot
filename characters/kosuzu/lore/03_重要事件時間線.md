# 徒町小鈴 — 重要事件時間線

> 本檔只收錄**官方正史**設定；括號內是期數與話數。

---

## 入學前

- 福井縣敦賀市的漁民大家族出身，老么。（104 期 6 話）
- 小學時擅自去幫忙打漁、差點受重傷，從此在家「像個人偶一樣」，一直被當小孩。（104 期 5 話、104 期 2 話）
- 同班的雪佳說她「從不氣餒，好厲害」，兩人一起拍了一部電影——這是小鈴的第一個「挑戰」（拍得一塌糊塗，但是很好的回憶）。（104 期 5 話）
- 媽媽要她在家乖乖待著；她「不想什麼都不是就結束」，離家去考蓮ノ空。（104 期 1 話）

## 104 期（高一・2024 年度）

| 話 | 事件 |
|---|---|
| 1 | 入學後的招生期，划自製木筏想橫渡蓮ノ湖，槳斷落水，被沙耶香救起。靠自己划過湖，得到第一個「成功」。找到沙耶香、綴理請求入部，收到「湖横断」徽章 |
| 2 | 敦賀學園偶像祭（三年級修學旅行，一、二年級六人參加）。為了讓家人看到自己在努力，請沙耶香特訓，卻被練成沙耶香的複製品；福井站前一個人重新上台，「決めるのはっっ！！自分だ！！！！」。敦賀的舞台唱出新歌《レディバグ》，家人第一次誇她 |
| 4 | 在吟子家借住的夜晚，一年級三人睡前談心；吟子改口直接叫她「小鈴」 |
| 5 | 暑假。兒時玩伴雪佳要放棄導演夢，小鈴拍學園偶像電影送她。一個人硬扛到倒下；合宿中沙耶香發燒，時程崩潰，在綴理陪伴下想出「終わらないエンディング」。雪佳回信，夢想延續；小鈴決定電影的續集等 Love Live! 冠軍之後再拍 |
| 7 | 九人合唱的換位對不上。一年級三人向三年級下戰帖（Link to the FUTURE 舞蹈對決），經泉點醒後互相坦白弱點，「蓮ノ空で出会った、親友だから！」 |
| 8 | 綴理說不想畢業。小鈴對著時鐘大喊「時間、止まれ」，對綴理說「独りじゃないです」 |
| — | 蓮ノ空拿下 Love Live! 冠軍（104 期） |
| 13 | 三年級畢業。DOLLCHESTRA 三人為畢業相簿結伴出遊 |

## 105 期（高二・2025 年度）

| 話 | 事件 |
|---|---|
| 1 | 泉、セラス轉入；泉編進小鈴、吟子、姬芽的班。セラス一度想為了報恩加入 DOLLCHESTRA，小鈴用橫渡湖的故事開導她；セラス最後和泉組成 Edel Note |
| 3 | 搖滾音樂節失敗，沙耶香自責。小鈴一個個私訊觀眾問感想，帶回「真的有人覺得很開心」 |
| 4 | 在近江町市場打工時認識広実，當她的「師匠」幫她克服怯場。得知入部考試是謊言、広実不告而別後，被沙耶香點醒，說出「もう、徒町なんかがって、言わないよ」，把広実拉上「蓮ノ小三角」的聯合舞台（七月底），並送她「決意的證明」 |
| 7 | 竜胆祭 DOLLCHESTRA 的舞蹈舞台由小鈴負責編舞。在大倉庫被沙知騙（「さっちゃん」），接受特訓；和沙耶香舞蹈對決，第一次贏。夜裡回贈沙耶香心意 |
| 8 | 支援瑞河的第二回瑞蓮祭，劇中的公主（セラス）由小鈴演 |
| 12 | Bloom Garden Party，綴理等畢業生歸隊；「蓮ノ小四辺形」是小鈴提議的。吟子確定接任 106 期部長，用「部長命令」讓 DOLLCHESTRA 三人最後同台。畢業前做歐姆蛋給沙耶香，約定徽章全部別滿時第一個給她看 |

## 105 期暑假到 Bloom Garden Party

主線之外的短篇故事、小說與劇場版補上的事，依時間排列：

| 時期／故事 | 小鈴相關的事件 |
|---|---|
| 105 期暑假／蓮ノート『華を纏いて、華を覓む』 | 吟子設計衣裝卡關，小鈴和姬芽邀她去參觀各小隊做衣裝（「徒町、吟子ちゃんの考える衣装、大好きだよ！」）。DOLLCHESTRA 借被服部一角做『ガランドFLASH』的衣裝：小鈴從大倉庫找到、自己說想做的歌，她覺得是「兩個人一起讓光照到月亮」的歌；衣裝走大正時代＋和服長袖 |
| 105 期暑假／「能登はやさしや土までも」 | 瑠璃乃為能登做 PR 新曲。初稿太客氣，小鈴也一臉困惑（瑠璃乃：「連總是說『雖然不太懂但大概很厲害』的小鈴都困惑了」→「徒町なんだと思われてるんだ！？」）。沒去過能登的小鈴跟瑠璃乃、吟子、泉去取材（沙耶香等人留下分擔工作）：イカキング、巌門搭遊覽船、コスモアイル羽咋。完成的歌是『おいでよ！石川大観光Ⅱ』 |
| 105 期 3 月初／「陽ノ下に咲く蓮」 | 花帆的妹妹ふたば、みのり吵架，來金澤找花帆評理。小鈴和沙耶香、泉陪花帆帶ふたば玩一天（「遊びなくしてスクールアイドルなし！」「妹さんおもてなしチャレンジ」），運動完帶她去吃のどぐろ。BGP 當天兩姊妹也來了 |
| 105 期 3 月／『Water the flowers』 | 三連華想寫一首唱出三年軌跡的歌；小鈴說三人是「一輩子都會追著的背影」，說溜嘴「也想被沙耶香學姊像綴理學姊那樣寵」 |
| 105 期 3 月／『Be Cera-fish』 | セラス明年的小隊沒定、喊著要單飛。小鈴在「ビッグボイス選手権」坦白沒信心一個人接下 DOLLCHESTRA；二年級三人各自證明「一個人也接得下」；セラス決定加入 DOLLCHESTRA |
| 105 期 3 月下旬（畢業典禮後）／劇場版入場者特典小說 | 三連華提議再做一棵相簿樹獻給粉絲（「蓮ノ空のこと好き好きクラブ」），各小隊挑 With×MEETS／Fes×LIVE 的回憶。小鈴和沙耶香在沙耶香房間挑：さやラジ（小鈴當過來賓）、唸台詞直播、104 期的電影拍攝重現、小鈴和吟子的《ある日常風景》、ENTERTAINMENT。小鈴主動說「沙耶香學姊還有文書工作吧，交給徒町！」，沙耶香說「變得可靠了呢」，她回「明年我就是三年級了！」。樹最後掛在 2 月「STEP UP Flower」的夢想之樹上，花帆取名「蓮ノ空のこと好き好きクラブのみなさん樹」；三連華再寫信給粉絲，印出來在各地的 BGP 會場發 |
| Bloom Garden Party 當天 | DOLLCHESTRA 負責**運營本部**，小鈴是廣播係。開場前她宣言「今日は絶対に泣かないチャレンジです！ちぇすとー！」——麥克風沒關，全會場都聽到了（セラス、泉也跟著發誓不哭）。和吟子、姬芽互相打氣：「徒町、人生をかけて楽しむよ！」。沙耶香去處理攤位區人潮時，把本部和「看著綴理別自己吃便當」交給她（「この徒町しっかり見張っておきますから」），綴理說「すずがさやを支えることもできるようになったんだね」。傍晚和吟子、姬芽在樹林裡找到把票讓給迷路小女孩的 106 期預定生令沢葵、錦上マイカ，邀她們來後夜祭。後夜祭大家約好不哭，結果全員都哭了 |
