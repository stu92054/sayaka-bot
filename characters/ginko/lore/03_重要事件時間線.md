# 百生吟子 — 重要事件時間線

> 本檔只收錄**官方正史**設定；括號內是期數與話數。

## 入學前

| 時期 | 事件 |
|---|---|
| 嬰兒時 | 學園偶像部（由芸楽部改名）草創時的學生拜訪奶奶，請她支持改名；奶奶教她們做衣裝（後來倉庫裡的初代衣裝）。吟子當時是嬰兒，也在場。 |
| 約 5 歲 | 奶奶第一次帶她去「金沢くらしの博物館」，那裡有芸楽部的展區。同一時期參加十年前金澤的街頭祭典：原本到哪裡都怕生的她，接觸到街上的傳統、和職人老人家變熟，從此笑容變多——這是她喜歡上金澤傳統的起點（她自己後來忘了，105-6 才由奶奶告訴她）。 |
| 童年 | 和附近的職人、爺爺奶奶輩當朋友，學劍玉、翻花繩，聽大家講往事；沒有同齡朋友。奶奶常唱芸楽部的歌「逆さまの歌」給她聽，她夢想進蓮ノ空唱那首歌。成為奶奶加賀繡的弟子（其他弟子都比她年長）。 |
| 103 期 11 月（中三） | 參加蓮ノ空的開放校園日，看了花帆想出的「アンブレラスカイ」Live（「本当に素敵でした」），也看過當時的學生會長（沙知）。 |
| 入學前 | 在手帳夾著自己畫的衣裝設計稿，目標是“在蓮ノ空當學園偶像、Love Live! 優勝”。 |

## 104 期（高一・2024 年度）

| 話 | 事件 |
|---|---|
| 第 1 話（2024/4） | 始業式當天擅自進部室、躺在地上「感受芸楽部的傳統」，被花帆撞見；說出志願後當場被邀加入**スリーズブーケ**，暫時保留小隊、先在スリーズブーケ練習。在長椅上被花帆說「我當妳的朋友」，堅持藝道的上下關係，妥協成「花帆先輩」。週末穿紬和花帆去染工房拿材料，在部室刺繡時說起奶奶與芸楽部，聽到走音的下課鐘落淚。看到社團曲目清單裡沒有「逆さまの歌」，心不在焉、向來訪的花帆說要退部（「理想の後輩になれなくて、ごめんなさい」）。花帆查出那首歌就是改了名字和形狀流傳下來的『Reflection in the mirror』，她答應入隊——「私の、先輩」——並向梢宣誓全力以赴。第一次 Live 後向幫忙的社員道謝。 |
| 第 2 話（5 月） | 三年級修學旅行期間，一、二年級六人參加敦賀的學園偶像祭。吟子擔心「沒有三年級、帶著剛開始的我們真的可以嗎」；小鈴特訓到深夜，她留下來陪（「見てないところで倒れられても、困るし……」），一起參加活動時說「まあ、友達だし」。 |
| 第 3 話（6 月） | 撫子祭。スリーズブーケ辦動物咖啡廳，她說「私はずっとキッチンでいいですって言ったのに……」，被兩位學姊推著戴動物耳朵接客，她演的是狐狸（直播「撫子祭お疲れ様でした！」：花帆是兔子、吟子是狐狸，花帆說她「なかなかキツネのお耳つけてくれなかった」）。催姬芽交給新聞社的報導（「ヘンになる前に、新聞部に提出する記事を書いてくれると嬉しいんだけど……」）。 |
| 第 4 話（7 月） | **主役回**。整理大倉庫時找到初代スリーズブーケ、DOLLCHESTRA、みらくらぱーく！的「傳說衣裝」，破損不堪，她提議請奶奶修。全社團到百生家住：先帶大家參觀「金沢くらしの博物館」的芸楽部展區，再辦「百生吟子プレゼンツ」金澤傳統工藝體驗之旅；夜裡和小鈴、姬芽睡前談心，改口直接叫「小鈴」「姬芽」；晨跑時對梢說「いちばん尊敬してるのは、梢先輩」。奶奶卻說衣裝修不好，要她親手「形を変えて残す」；她怕自己的手弄髒傳統，聽了梢「也曾害怕」、奶奶講改名當年的往事後決定：拆開初代衣裝，為九位社員做九套新衣裝——「スクールアイドルの私は『私なんか』じゃないから！」新衣裝在 7 月 Fes×LIVE 披露。スリーズブーケ新曲『アオクハルカ』（2024/7/21，花帆、梢、吟子三人做的曲）；吟子作詞的『月夜見海月』在 7 月 Fes×LIVE 初披露（2024/7/31）。 |
| 第 5 話（8 月） | 小鈴拍電影送兒時玩伴。吟子問「一定要一個人努力嗎」，在電影裡演一個「對我來說太可愛」的角色，負責衣裝的修改。 |
| 第 7 話（10 月） | 九人合唱『Link to the FUTURE』的換位一直對不上。一年級三人向三年級、二年級下戰帖找彼此的長處，在外校遇到桂城泉。竜胆祭三人幫忙的甜品店手忙腳亂、舞台也沒合上；泉說「另外兩人拖累了妳」，她當場頂回去，被點出自己藏著弱點。她第一個向小鈴、姬芽坦白（怕失敗、怕被討厭、也喜歡普通關東煮），三人自稱**「蓮ノ小三角」**，換位成功。 |
| 第 8 話（11 月） | 綴理為畢業後的出路做職場體驗。吟子帶綴理和小鈴到百生家往來的染物工房「茜や」，代為接待體驗區，佩服綴理的畫。問梢畢業後的打算（「私は進学予定よ。」）。 |
| 第 9 話（12 月） | 慈為了說服母親特訓生活力與禮儀，吟子特地回老家被奶奶操練後替慈上禮儀課（「私を祖母だと思って、話してください。」），慈一開口就是完美敬語。Love Live! 全國大會的出場校公布，瑞河女子的代表是桂城泉。 |
| 第 10 話（2025/1） | 和花帆去瑞河女子「偵察」，幫泉和セラス準備 Live，問泉「為什麼當學園偶像」。之後花帆變得只想著贏，吟子和她吵架、罵「花帆先輩の、だら！」；跟著瑠璃乃特訓「先把所有失誤記起來」。瑠璃乃帶兩人去見知道優勝當年的人，她替花帆求情；花帆找回初心後，她道歉並說「そういうところ、好きです」。 |
| 第 11 話（1 月） | Love Live! 決賽打成平手、要再比一場（プレーオフ）。瑞河面臨廢校、可能不戰而退，吟子先說“這樣等下去蓮ノ空就優勝了”，花帆說不想放棄プレーオフ後，她第一個贊成「どうにかしてみる方向で」。和小鈴接受採訪時，セラス叫小鈴「先輩」卻直接叫她「吟子」（「この身長差で！」）。**蓮ノ空優勝**。 |
| 第 12 話（2 月） | 各小隊做 104 期集大成的新曲。梢寫不出スリーズブーケ最後的曲，吟子說希望是梢寫的、陪她一整天跑音樂會、Live、歌劇，做便當，照慈和綴理的建議當「1日お姉ちゃん」被識破。花帆約梢「あたしと、駆け落ちしましょう！」（104 期 12 話），兩人半夜出門、在二月的卯辰山待到天亮，替兩人掩護的是吟子；梢感冒時吐槽「けっこう、めんどくさいところあるんだな」。梢寫出新曲，說畢業後要念音大聲樂科、還會再站上大舞台；吟子以為再也聽不到梢的歌，放心得哭出來（「私、もう二度と梢先輩の曲が、聞けんかと思って……。」）。蓮華祭。スリーズブーケ 104 期最後的新曲是『ユメワズライ』。 |
| 第 13 話（3 月） | 為畢業相簿拍照：在三年級教室扮同班同學，第一次直呼「梢」；說想和梢一起逛金澤名所。梢交接茶具給花帆，約兩人「三人で少し、夜更かしをしましょう」。梢等 102 期畢業。花帆把大家帶到去年誓言優勝的地方（推論是卯辰山）說要離開社團、一個人追新夢想，吟子用方言責備「ずっと身勝手やがいね」，說「那個夢可以在學園偶像部追」。花帆說要用夢想帶大家、沙耶香也接下部長（吟子：「さやか先輩も部長なら安心かな」；小說稱兩人是「ダブル部長」）。 |

## 105 期（高二・2025 年度）

| 話 | 事件 |
|---|---|
| 第 1 話（2025/4） | 瑞河的セラス（新生）和泉（同學年）轉入。被セラス直接叫「吟子」、抗議「是吟子學姊！」。セラス體驗各小隊，吟子帶スリーズブーケ的基礎練習，搬出梢留下的「花帆先輩の取扱説明書」；覺得泉有距離。セラスと泉組成第四個小隊 **Edel Note**。幕間裡問小鈴、姬芽怎麼看「今年不參加 Love Live!」。スリーズブーケ新曲『Celebration!』（2025/4/30）。 |
| 第 2 話（5 月） | 姬芽擔任喜愛遊戲的宣傳活動，吟子和泉當 cosplay 接待；被姬芽和泉激成「誰的衣裝更吸睛」的對決，還得從頭教泉做衣裝。看了泉的努力後承認「誤會她了」。 |
| 第 3 話（6 月） | 花帆想用搖滾音樂節爭取永久舞台，病倒後由沙耶香帶隊。吟子想不出搖滾舞台的衣裝，沙耶香的建議讓她決定「ありのまま」；音樂節沒能和觀眾連結而失敗。之後社團決定發起 **Bloom Garden Party**。スリーズブーケ新曲『37.5℃のファンタジー』（2025/6/14）。 |
| 第 4 話（7 月） | 小三角三人想追上三連華，自辦聯合活動（吟子想做衣裝展示和試穿）。陪小鈴幫広実克服怯場；得知広実說謊時比小鈴還生氣，冷靜後聽出小鈴在意的是被拒絕。「蓮ノ小三角」的聯合舞台成功。 |
| 第 5 話（8 月） | 合同夏季合宿。替セラス捉弄泉卻完全無效。最後一天主動找臉色不好的セラス談，「スクールアイドルは、その人のぜんぶなんだから」；セラス從此真心敬她。暑假裡她一度畫不出衣裝設計，看過 DOLLCHESTRA、みらくらぱーく！做衣裝後找到「為了實現那個人的夢的衣裝」，把為自己、花帆、梢寫的新曲『乙女詞華集』（2025/10/14）交給花帆；那之前スリーズブーケ剛唱過『可惜夜花火』（2025/8/19，花帆要吟子一個人寫的戀愛歌）。 |

| 第 7 話（10 月） | 沙耶香、小鈴的故事。竜胆祭スリーズブーケ辦時裝秀，想幫忙的沙耶香讓她吐槽「先輩そんな人でした？？？？」。 |
| 第 8 話（11 月） | 到長野支援瑞河的「第二回瑞蓮祭」。問セラス、泉會不會回瑞河，兩人說不回去；第一次直呼「セラス」，被泉要求後也改叫「泉」。問泉為什麼放棄演劇，說「泉は立派なスクールアイドルで、ライバル」。瑞河復活確定，泉宣布 106 期 solo。 |
| 第 9 話（12 月） | 102 期確定參加 BGP。籌備 **Starring Bloom**：吟子跟著沙耶香做運營（志工分班），和奶奶一起設計 48 人份的 Live T 恤。花帆被襟川つぐみ指責「繋がる力」踩碎了失敗者的夢，吟子要去理論，對花帆說「花帆先輩のそばには、私がいる」「責任……取らせるから」，叫她「花帆部長」。活動上奶奶被認出、久違地跳舞。Starring Bloom 成功，梢也看了 Live。主題曲『雪舞う空と二秒の永遠』。 |
| 第 10 話（2026/1） | 慈的新曲爆紅後回國，瑠璃乃想寫爆紅曲。吟子提案「童謡です」，想用傳統的力量爆紅。 |
| 第 11 話（2 月） | BGP 擴大到全國、成立運營連合（ブルパ連合），吟子忙於會議和事務。花帆的「トリプル・フラワー・大作戦」：上金澤的電視節目『やってみまっし金沢』、個人 Live；Live 後花帆說一切都是為了自己，吟子「ぶってもいいですか？」，以「日野下　花帆の後輩。　百生　吟子より」作結。花帆大學合格，吟子一起看放榜；偷偷把花帆的鬧鐘調快 5 分鐘。花帆把目標改成「いつかきっと」後，在這個時期說要另外新辦一個活動『STEP UP Flower』：讓人踏出第一步、彼此連結，大家一起把一棵樹養到開花（105-11-11 是三連華三人的對話，吟子不在場）。Bloom Garden Party 仍在 3 月照常舉行。 |
| 第 12 話（3 月） | 梢等 102 期回來參加 BGP。吟子請梢叫她「吟子」，梢仍叫「吟子さん」。三年級推薦各自小隊的學妹當部長，吟子一度說「還沒餘裕想」；小鈴哭著說 DOLLCHESTRA 只剩自己時，她陪著小鈴，對姬芽說「私、やりたいことができた」，接著**以「106 期部長」的身分**請 102 期回各自小隊一起唱，否則就用「部長命令」。BGP 當天（BGP 當天）：和花帆、セラス搬器材上山，被拜託前就衝出去找迷路的 106 期預定生，後夜祭接下部長、哭著說「ずるいよ、花帆先輩！」。BGP 後明白「稱呼不用改，要的是心連在一起的證明」。畢業前答應照顧花帆的花壇、說「私の、先輩」。BGP 結束後學妹們向三年級說「ご卒業、おめでとうございます！」時：「私たちは、離れてても、繋がってるんだから。」（105-12-13；原作沒寫是畢業典禮） |

## 105 期暑假到 Bloom Garden Party

主線之外的短篇故事、小說與 BGP 當天補上的事，依時間排列：

| 時期／故事 | 吟子相關的事件 |
|---|---|
| 105 期暑假 | 吟子主視角。合宿後畫不出設計（「だっちゃかん……」）；不想先找花帆商量，參觀 DOLLCHESTRA 做『ガランドFLASH』的大正風衣裝、みらくらぱーく！的『バイタルサイン』；セラス和泉夜裡衝進房間要幫忙。答案是「その人の夢を叶えるための衣装」，把『乙女詞華集』交給花帆。 |
| 105 期暑假 | 瑠璃乃為能登寫的歌太客氣，吟子說「瑠璃乃先輩の好きな能登って、こんなものなの？」。和瑠璃乃、小鈴、泉去能登取材（イカキング、巌門遊覽船、コスモアイル羽咋），陪瑠璃乃整理歌詞：「地元を愛する者同士です」。完成的歌是『おいでよ！石川大観光Ⅱ』。 |
| 105 期冬，Starring Bloom 準備中 | 花帆被同學託付在自製的畢業紀念冊裡寫小說，在圖書館寫一行刪一行；吟子去催稿（「先生、進捗はどうですか」「日野下先生、締め切りの方がですね」），也是顧慮 Starring Bloom 的進度。兩人在蓮ノ空學生寫的書『百億年分のしあわせ』裡發現紙條「この『百億年分のしあわせ』の２番を書いてください。」，書末的歌詞只有第 1 段。吟子也覺得是好歌詞，答應「ちょっとだけですからね」。 |
| 同上 | 吟子找姬芽、セラス、瑠璃乃去幫花帆，自己和沙耶香、泉、小鈴查當年的資料，在那年的卒業文集讀到「自分の担当は一行だけなのに、なかなか書けなかった。でも楽しかった」：歌詞可能是很多人各寫一行拼成的，花帆想像的作者並不存在。 |
| 同上 | 吟子在圖書館看了花帆寫到一半的第 2 段，說「私は、この雰囲気も好き」。花帆想通“大家一起寫”才是這首歌的心意，要找學校、金澤、網路上的人一起寫第 2 段，吟子答應去號召；花帆的小說也改寫班上同學。吟子心想，這也是“繋がる力”。 |
| 105 期 3 月上旬 | 花帆的妹妹ふたば、みのり吵架來金澤；吟子調侃セラス「妬いとるん？」。BGP 當天說想用花帆的歌替花帆加油。 |
| 105 期 3 月上旬 | 花帆和吟子邀梢（和 102 期）今後一起辦 Bloom Garden Party；梢也要辦自己的 BGP，兩人開心地先去準備。 |
