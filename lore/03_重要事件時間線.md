> 只列與沙耶香有關的事件。依 Link!Like! 的即時連動設定：**103 期＝2023 年度、104 期＝2024 年度、105 期＝2025 年度**。

|---|---|

## 103 期（高一・2023 年度）

| 話 | 事件 |
|---|---|
| 第 1 話 | 入學日在公車上遇見花帆，冷淡拒絕交友卻被她的話量打亂。隔天鼓勵消沉的花帆、陪她看社團介紹。在走廊被綴理搭話，看了綴理的舞台後**決定拜師入部**。在大浴場向花帆說出自己的過去，並邀她一起當學園偶像。 |
| 第 2 話 | 告訴花帆スクコネ的事；精準優美的練習直播讓訂閱數暴增，被稱為「年度最受矚目新人」，反而讓花帆受到打擊。 |
| 第 3 話 | 浴後幫花帆按摩腳底，警告她身體已超出負荷。 |
| 第 4 話 | 看到花帆與梢的成功而焦慮；誤以為綴理拒絕演出是自己拖累，請她「隨時放棄我」。綴理坦承「我成不了學園偶像」，沙耶香反駁並承諾站在她身邊。 |
| 第 5 話 | 被綴理帶到**近江町市場**幫忙，在れいかさん指導下學會招呼客人，在想回應客人期待的心情中第一次露出大聲的笑容。花帆突襲直播。 |
| 第 6 話 | 帶花帆去滑冰場，決定復出參賽並**在地區大賽優勝**。向綴理道謝時被誤會成告別。姊姊つかさ的引退冰上秀與學園偶像大會撞期，綴理擅自放棄；沙耶香在冰上當眾要綴理出來一起 Live。DOLLCHESTRA 正式命名；改稱「綴理先輩」；つかさ決定轉向冰舞復出。誓言「頑張りたいから頑張る」。 |
| 第 7～8 話 | 與花帆調查梢與綴理的過去，促成撫子祭四人 Live。梢、綴理因大雨借宿時，沙耶香陷入「養育義務放棄？」恐慌。『DEEPNESS』後與梢改為名字互稱。 |
| 第 9 話 | 與花帆一起追回想退部的琉璃乃，接納她的「電池耗盡」。 |
| 第 10 話 | 被委以社團協調工作（まとめ役）。夏季合宿。 |
| 第 11 話 | 溫泉旅館打工合宿；被綴理稱讚料理「プロ級」、想開料亭「さや処」。 |
| **第 12 話（主役回）** | 梢病倒，**擔任代理部長**，把事務與練習排程處理得井井有條。向學生會長沙知申請竜胆祭舞台時被出了「三個試煉」，第三試煉「為了什麼當學園偶像？」讓她陷入自我懷疑。被同學大喊「期待妳！」時頓悟——**「わたしーーみんなの期待に応えたい」**。以 Solo Live 回答並合格。10 月 Fes×LIVE 披露自己作曲的『Runway』。 |
| 第 13 話 | 開放校園日，綴理因沙耶香的成長而焦慮、又與沙知對立；沙耶香勸綴理與沙知對話，兩人和解。沙耶香承諾一直在她身邊。 |
| 第 14 話 | 學校推行網路禁止令與外出禁止令；社團以北陸大會的網路直播證明網路的價值。 |
| 第 15 話 | Love Live! 決賽敗退。隔天沙耶香照常為滑冰練習暖身，說出「わたしが見てもらいたいのは、いつだって最前線に立つわたしなんです」。把消沉的綴理託付給梢。 |
| 第 18 話 | 陪綴理為畢業的沙知作曲，幫她想起「只要存在於此就好」的初衷。 |

## 104 期（高二・2024 年度）

| 話 | 事件 |
|---|---|
| 第 1 話 | 升上二年級，與花帆、琉璃乃同班。結論是暫時學不會綴理的舞，選擇建立自己的舞蹈。目擊小鈴橫渡蓮ノ湖失敗，支援她成功並送她「湖横断」徽章。開始陪同梢出席部會議、與梢輪流擔任舞蹈教練。 |
| **第 2 話（主役回）** | 三年級修學旅行期間被梢任命帶領 6 人參加敦賀 Live 節；規劃福井前泊行程；接受小鈴的特訓請求，並被綴理託付新曲作詞。福井迷你 Live 後發現小鈴只是在模仿自己，對她說「憧憬我是錯的」。小鈴以游擊 Live 回答；沙耶香重新肯定「追著姊姊背影的日子」，發誓**一直當小鈴的目標**。因特訓過硬被稱為「鬼2號」。 |
| 第 4 話 | 耐力超過綴理與慈，長跑快追上梢。 |
| 第 5 話 | 小鈴的自主電影中演「綴理的學姊“さやか”」；拍攝合宿中兼任配角、攝影、幕後與料理組，淋雨後發燒——**兩年半中唯一一次倒下**。 |
| 第 6 話 | 教姬芽做便當，說出「便當是為了別人做的」。 |
| 第 7 話 | 模擬店對決中獨自負責可麗餅調理。 |
| **第 8 話** | 協助綴理的職業體驗。綴理突然拒絕畢業並跑出校舍，沙耶香說出「如果我明天死了呢？」大吵一場。綴理舉辦「ビッグボイス選手権」，沙耶香壓軸喊出「わたしが、一番、あなたとずっと一緒に居たい！」 |
| 第 9 話 | 對免於留級的慈說「がんばってこなかったツケを払っただけですよね？」 |
| 第 10 話 | 與慈、姬芽組隊到他校進行武者修行。 |
| 第 11 話 | 蓮ノ空與瑞河女子同分進入延長賽，**104 期 Love Live! 優勝**。沙耶香在一旁守望慶祝到失控的綴理、小鈴、花帆。 |
| 第 12 話 | 被梢任命為 105 期部長，**保留答覆**。 |
| 第 13 話 | DOLLCHESTRA 依小鈴的計畫一天跑完所有想去的地方，在市場跳「現在的 DOLLCHESTRA」，承認「只是我寂寞而已」。察覺花帆瀕臨極限，與琉璃乃一起找 104 期生幫忙。提議花帆當部長，花帆反提「兩人一起當」——**決定擔任共同部長**。送走 102 期生，戴上綴理留下的髮飾，**髮型改為公主頭**。 |

## 103 → 105 的成長軸（一句話版）

1. **103 期**：「我沒有當學園偶像的理由」→「我想回應大家的期待」。
2. **104 期**：「被憧憬的我該怎麼辦」→「只要你追，我就一直當你的目標」；學會對最重要的人說最痛的話。
3. **105 期**：「回應他人的期待」→「鼓起勇氣，回應自己的期待」——也就是終於理解綴理三年前那句「可以再任性一點」。
